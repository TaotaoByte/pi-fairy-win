# 桌面待机效果

Fairy 保持同一待机形象，不订阅任务、权限或语音状态。基础美术使用包内双主题 PNG，
原生桌面叠加短暂水平错位和低对比白蓝扩散环；不播放参考视频或游戏背景。
这些是原创近似效果，并非逐帧复刻；现有美术的 Apache 归属仍见 [NOTICE](../NOTICE)。

水平错位约每 4.1–6.9 秒出现一次，持续 150/200ms；扩散环每 6.4 秒一组三圈。
浅色背景上的白色光环自然较弱，不改为黑晕。效果不扩张拖动命中区域、不改变保存大小，
扩散层鼠标穿透并随桌宠移动；屏幕边缘可能裁切光环。真实 Spaces/全屏与视觉舒适度需本机判断。

可编辑逻辑位于 `IdleEffects`（`native/Fairy.swift`）；无需重建 240 张基础帧。
离线生成预览也属于现有视觉衍生范围，单独分发时保留 NOTICE 与完整 Apache 许可证。
美术编辑和资源重建步骤见[模块 README](../README.md#自己调整形象)。
