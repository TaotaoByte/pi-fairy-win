# Fairy 桌面动画与资源契约

仅支持 macOS 原生桌面，无终端渲染或后端选择。会话工厂不启动后台资源；
非子进程交互式 TUI 才能连接。旧后端命令只报中文错误，不改变显示状态。
旧 `--fairy-anim-mode` 仅作为拒绝迁移保护：任何显式值都禁止本次自动或命令连接，
释放继承租约，不影响语音、帮助、off 和独立 welcome 设置控制。

原生显示、IPC、3 秒最后租约宽限、全局主题、大小/位置设置 v2、开场音频时序不变。
完整运行契约见 [README](../README.md)、[开场](../../../docs/DESKTOP-INTRO.md)和
[休息提醒](../../../docs/REST-REMINDER.md)。桌面 signal/ripple 属原生特效，
下述 PNG 仅是无故障/扩散效果的基础美术帧。历史像素/终端契约已退役。

## 可编辑资源与几何

- `assets/fairy.svg`：可直接打开的独立 SVG，256×256 PNG 输出。
  上游中心 (80,80)，圆盘半径68，眼白48，瞳孔16，右下高光 (98,100.5)/11。
  外光晕79、眼白光晕56、高光晕18；保留柔和径向 alpha 衰减，不使用矩形底板。
- viewBox 从上游 `0 0 160 160` 改为 `-1 -1 162 162`，外晕最远边界外留2单位。
  输出 alpha bbox 为 (3,3,253,253)。圆盘半径107.46px，旧版108px，主体只缩小
  约0.5%，不是为超大光场大幅缩小。无位移 bob，不会动态裁掉光晕。
- 两个主题都保留白色外/眼白光晕、近白高光晕与1.2单位白色盘沿。独立1.8单位
  supporting stroke 在白边背后露出约0.3单位（0.47px），浅主题深色、暗主题浅色。
  白光在白背景上天然较弱；通过支持边识别轮廓，而非将白光替换为黑光。
- 四角圆盘/圆角方形与其3°初始角度、分层蓝色虹膜及最后绘制的高光来自上游。
  没有大范围扫描线光场、扩散脉冲、故障、眨眼、状态表情或任务响应。

## 可编辑节奏与闭合周期

`assets/idle-motion.json` 是小型参数文件：周期、Bezier、四层尺度端点及相位领先。
`scripts/frame-svg.mjs` 仅在离线构建时求值；高光使用蓝虹膜相位但最后绘制。
只有四角旋转，高光与瞳孔均不旋转。所有尺度绕 (80,80) 独立缩放，整张圆盘
不闪烁、不一起缩放。

| 参数 | 上游正常待机 | 本次离线适配 |
| --- | --- | --- |
| 完整呼吸周期 | 1440ms | 1500ms（周期 +4.17%） |
| 四角完整旋转 | 15000ms | 12000ms（角速度 +25%） |
| 眼白尺度 | .985↔.91 | 保持 |
| 外虹膜 / 蓝环 / 瞳孔 | 1↔.90 / 1↔.87 / 1↔.85 | 保持 |
| 相位领先 | 0 / 45 / 90 / 180ms | 0 / 46.875 / 93.75 / 187.5ms |
| 曲线 | cubic-bezier(.72,0,.28,1)，往返 | 保持，数值反解 x |

选择保持现有运行时资源契约：120帧 × 50ms = 6s、20 FPS，每主题120张 PNG。
6s 包含4次呼吸与180°旋转；四角90°对称，因此精确闭合，不是截取上游6s片段。
实际最小联合周期是3s（2次呼吸、90°），存储两次相同循环以保持原生资源契约。
有60张不同 PNG，每相邻帧仍变化，无重复终点停顿。避免上游1.44s与3.75s求最小
公倍数得到180s/3600帧每主题。生成器拒绝不闭合的参数组合。

重建：`npm run build:frames`；预览：`python3 scripts/build-previews.py`（Pillow）。
`docs/vector-preview.png` / `docs/vector-idle.gif` 是深浅底色合成预览，**不是终端截图**；
仅这些预览有背景，实际桌面 PNG 全透明。依赖 resvg 仅离线使用，无运行时绘图/网络。
修改 SVG 时保留 corners、sclera、iris-outer、iris-blue、pupil、highlight 的 transform
锚点与 `#dceaff` supporting stroke；缺失/重复锚点必须报错。

测试同时覆盖源参数幅度/相位、Bezier、连续时刻闭合、重建一致性和实际 PNG 的
半径变化、旋转、透明边界、白色晕/主题支持边与循环接缝。原生窗口的真实显示效果仍需独立人工验收。
