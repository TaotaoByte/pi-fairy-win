# 桌面开场与退场

开场每个**新的共享桌面生命周期**播放一次，不随新 Pi、`/reload` 或宽限期内重连重播。
`/fairy-anim welcome` 查询，`/fairy-anim welcome full|simple` 保存下一次选择；默认 full。
命令不启用桌面、不立即重播。位置和大小全局保存，详见[动画模块](../modules/animation/README.md)。

## 完整与简洁模式

- **full（10 秒）**：静态噪声 → 本地时钟 → 错误窗口 → HDD 进度条 → Fairy 显现 → 落位。
  全部为程序绘制与包内 PNG，不含参考视频、游戏截图或 HDD 应用；进度条不表示扫描或真实系统状态。
  7.2 秒尝试播放唯一的 welcome-7；缺失时不换成其他欢迎语，语音可持续到落位之后。
  原创程序合成 SFX 独立播放，10 秒结束；背景先在 9.3 秒淡出。
  有三次轻微变暗脉冲，不构成光敏安全认证。[SFX 来源与重建](../modules/animation/assets/intro/README.md)。
- **simple（2.4 秒）**：透明 Fairy 在中心生长后移到保存位置；使用 welcome-1 至 6，
  无全屏遮罩、HDD、脉冲或 SFX。移动期间鼠标穿透，拖动与菜单暂不可用。
- 两种模式优先保存的显示器与位置，否则回退到可用屏幕右上方并夹紧边界。
  显示器缺失的临时位置不覆盖保存位置，动画中间坐标不保存。
- 最后连接断开后有 3 秒重连宽限；提交退场后微放大再原地收缩淡出（0.95 秒），
  同时尝试告别语音。新连接需等待旧 helper 退出；详见[共享音频](LIFECYCLE-AUDIO.md)。

## 输入、显示与启动限制

完整开场只覆盖选定的一块显示器，**吸收该遮罩上的鼠标点击与滚动，无 SKIP 或点击关闭**。
不抢键盘焦点：打字、Escape 仍可能送到原应用；Escape 不关闭开场。这不是安全屏障。
不申请辅助功能、录屏权限，不显示在锁屏/安全 UI；macOS 可限制 Spaces、全屏及受保护窗口。
真实多屏、输入路由、物理首帧、音画同步和流畅度不由离屏测试保证。

显示布局/分辨率/缩放改变会取消开场并安全落位；无屏幕时隐藏，屏幕恢复后不重播。
最后租约丢失取消开场并停止欢迎，宽限期重连不重播。主循环间隔超过一秒会在恢复时取消；
这不能保证 OS 挂起或主线程卡死期间及时清理。
SFX 缺失、失败或准备过慢时静音，不延迟视觉或欢迎；单次时间校准不保证物理同步。

普通插件在 `session_start` 启动，**不能保证早于 Pi TUI**。首次使用可能异步编译 Swift。
`npm run prepare:desktop` 可显式提前编译缓存，不启动窗口或声音；缓存被清理后需重新准备。
[可选 zsh 提前入口](STARTUP-ENTRY.md)需另行启用，只承诺软件 ready，不承诺物理首帧。

## 已知退出风险

显示取消和缺失 welcome-7 的原生模拟测试曾超过六秒退出预期，原因、频率与生产相关性未知，
**未声称修复**。可能延迟 helper 退出及锁释放；六秒是快速录制 fixture 的预期，不是生产退出上限。
缺音频不应阻塞视觉时间线，但静态断言不能排除这项原生风险。
若连接超时，可在旧 helper 正常退出后 `/fairy-anim off` 再 `on`；不要强杀其他会话的 helper。

更新或回滚须释放所有桌面租约，等宽限及告别结束后重启全部 Pi；`/reload` 不替换活着的旧 helper。
不删除缓存或偏好作为排障手段。见[安装与回滚](INTEGRATION.md)。
