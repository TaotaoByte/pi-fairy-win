# 共享休息提醒

集成版由共享桌面 owner 调度一个**清醒桌面生命周期**时钟：从 Fairy 首次可见开始，
一小时后且开场/生命周期声音结束时，在旁边显示不抢键盘焦点的提示面板。
这不是工作时长测量；不监视输入、不检测工作、不申请辅助功能权限，也不保存提醒设置。

面板没有关闭、忽略、超时或外部点击消失路径；跨休眠及长时间未答复保留，直到明确选择：

- **稍后 · 5 分钟**：从点击起五个清醒分钟后再提醒。
- **去休息 · 1 小时**：从点击起一个清醒小时后再提醒。

按钮均静音。显示时尝试一次 activity-1 至 3，有多个可用文件时避免紧邻重复。
其中“已连续工作一小时”是既有语句，不表示监测了实际工作。缺失/失败音频不阻塞面板与计时。
活动语音预算 9 秒；不是硬性端到端播放/退出保证，见[共享音频](LIFECYCLE-AUDIO.md)。

OS 睡眠不计入时钟；新连接、reload、提前入口接管或最后连接的三秒宽限保留同一轮次。
告别中断活动语音；提交退场关闭面板并停止调度，新生命周期重新计时。
面板随桌宠移动并夹紧屏幕，尺寸菜单避免与其重叠；极小或特殊虚拟屏幕的可读性不能保证。
真实休眠恢复、焦点、Spaces、多屏与扬声器行为仍需本机验证。

**`/fairy-voice off` 不静音共享提醒。** 集成版不运行旧的每 Pi 小时提醒；
`/fairy-voice test activity`（或 `activity_reminder`）只说明共享归属，不播放或改变调度。
没有桌面连接时不提供独立提醒；其他任务/权限语音仍独立管理，可能重叠。
更新已运行 helper 须正常释放全部租约再启动；不要强杀其他会话。
